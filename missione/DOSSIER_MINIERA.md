# DOSSIER MINIERA — setaccio skills di ai-engineering-from-scratch (1/11)
CONTESTO: il capo ha una flotta di agenti CLI (OpenCode, Goose, OpenClaw, Hermes,
Secondhand, Freebuff) che bevono da un router locale ("cervello"); progetti
principali: INSTAGRAM STUDIO e YOUTUBE STUDIO (contenuti social); appunto-idea
sulla monetizzazione; 28 skills gia' installate in .agents/skills.
COMPITO: per OGNI riga (nome skill + descrizione) dai UN verdetto:
  🟢 FLOTTA     = utile ORA agli agenti/cervello del capo
  🔵 IG-STUDIO  = utile al progetto Instagram
  🔵 YT-STUDIO  = utile al progetto YouTube
  💡 MONET      = utile all'idea monetizzazione (solo annotare)
  🅿️ PARCHEGGIO = utile ma non ora (scrivi QUANDO servira')
  ❌ SCARTO     = inutile per il capo (scrivi PERCHE' in 5 parole)
  ⚠️ APRI       = descrizione insufficiente, serve aprire il file (solo se VERO dubbio)
Una skill puo' avere 2 tag (es. 🔵IG+🔵YT). NIENTE voti a memoria su cose ignote:
se non capisci, ⚠️APRI. RISPONDI SOLO con la tabella:
| skill | verdetto | motivo (max 12 parole) |
Stile ASD-STE100 all'80%: frasi corte, una idea per riga, niente fronzoli.
