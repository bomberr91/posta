# Modelli di Intelligenza Artificiale Disponibili su http://127.0.0.1:20129/v1

## 1. Introduzione
L'endpoint locale `http://127.0.0.1:20129/v1` offre un'ampia gamma di modelli di intelligenza artificiale open-source che possono essere utilizzati per vari compiti, tra cui generazione di testo, completamento di codice, analisi di dati e molto altro. Questo report fornisce una panoramica dettagliata dei modelli disponibili, le loro caratteristiche principali e le loro applicazioni pratiche.

## 2. Software del Server Locale
L'endpoint `http://127.0.0.1:20129/v1` è gestito dal software `opencode-free-bridge`, che agisce come un ponte compatibile con OpenAI per i modelli free-tier di OpenCode. Questo software consente di utilizzare vari client come 9Router, LiteLLM, Open WebUI, Continue, Cursor e agenti di codifica direttamente con l'endpoint locale [1].

### 2.1 Configurazione del Server
Il server `opencode-free-bridge` è configurato per ascoltare su `http://127.0.0.1:20129` e fornisce un'interfaccia compatibile con OpenAI. È possibile configurare il server utilizzando le variabili d'ambiente elencate nella documentazione ufficiale [1].

### 2.2 Integrazione con Client
Il server supporta vari client, tra cui 9Router, LiteLLM, Open WebUI, Continue, Cursor e agenti di codifica. È possibile configurare questi client per utilizzare l'endpoint locale specificando l'URL di base `http://127.0.0.1:20129/v1` e una chiave API fittizia `public` [1][2].

## 4. Caratteristiche Principali dei Modelli
I modelli disponibili su `http://127.0.0.1:20129/v1` presentano diverse caratteristiche principali che li rendono adatti a vari compiti:

### 4.1 Architettura
- **Transformer**: La maggior parte dei modelli disponibili utilizza l'architettura Transformer, che è nota per le sue capacità di elaborazione del linguaggio naturale [4].
- **Mixture-of-Experts (MoE)**: Alcuni modelli utilizzano l'architettura Mixture-of-Experts, che è nota per le sue capacità di elaborazione del linguaggio naturale e ragionamento [6].

### 4.2 Numero di Parametri
